# Application to a Published Study Reference Paper

This folder identifies the published paper used as the application to a published study:

To QG, Stanton R, Schoeppe S, Doering T, Vandelanotte C. *Differences in
physical activity between weekdays and weekend days among U.S. children and
adults: Cross-sectional analysis of NHANES 2011-2014 data.* Preventive Medicine
Reports. 2022;28:101892. https://doi.org/10.1016/j.pmedr.2022.101892

The article is available from the publisher through the DOI above. The PDF is
not redistributed in this repository; readers can use the publisher record to
trace how the decision-tree published-study application answers, dataset reconstruction rules,
and visualisation examples were derived.
