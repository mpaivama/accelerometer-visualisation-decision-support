# Extended data

This directory contains the six extended data files supporting the manuscript
*Visualising accelerometer-based 24/7 movement behaviour data: the LABDA
decision-support toolkit*.

The documents retain their manuscript-approved "Supplementary Material"
filenames, while their document headings identify them as Extended Data Files
for submission to Open Research Europe:

1. **Supplementary Material 1.docx (Extended Data File 1):** NHANES data
   sources, reconstruction procedures, inclusion and exclusion criteria,
   weighting decisions, derived variables, and known limitations.
2. **Supplementary Material 2.docx (Extended Data File 2):** Structural audit
   of the decision-tree logic and recommendation outputs.
3. **Supplementary Material 3.docx (Extended Data File 3):** Full description
   of the decision tree and its output fields.
4. **Supplementary Material 4.docx (Extended Data File 4):** Complete
   visualisation checklist.
5. **Supplementary Material 5.docx (Extended Data File 5):** Full
   decision-tree application to the research questions from the published
   NHANES study.
6. **Supplementary Material 6.docx (Extended Data File 6):** Complete catalogue
   of visualisations generated for the toolkit application and simulated
   examples.
